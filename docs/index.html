How the study checks itself

A backtest can be tuned until it looks good. Four rules keep this one from doing that, and each is in the repository for anyone to check.

  1. Write the test down first

    Each round's hypotheses, periods and pass bars go into a pre-registration file before any result is computed.

  2. Read the test period once

    v1 read 2018–2024 one time. v2 and v3 test on 2001–2017 and correct the Sharpe for the number of settings tried.

  3. Keep every result

    Six of eight tests were not supported. They stay here with their numbers and a link to the full write-up.

  4. Wait for new data

    Every date before 2026-12-01 has been seen by the researcher or may sit in TimesFM's training data. Only the forward test is clean.

Method notes

Open any note for the detail. Each one links to the file that does the work.

Timing

Signals use data up to the close of day t; the position earns day t+1.

Every signal uses returns up to and including the close of day t. The position earns day t+1. Signals are computed on the full history and only then cut to the chosen period, so a period never changes what was known on a given day.

Source: docs/trend_lite.py, tests/test_lookahead.py

Costs

Per-instrument costs and rolls on every trade; no market impact in the lab.

Per-instrument one-way cost (v1 cost_bp) on every trade, plus a roll cost of two trades per contract roll, times the cost multiplier. No market impact and no capacity limit in the lab; the paper's capacity table uses square-root impact.

Source: data/instruments.json, configs/universe.yaml

Labels

Contaminated, seen and forward: which dates could have leaked into the model or the researcher.

TimesFM may have been pretrained on these years, so every date before 2025-10-01 is contaminated. From 2018 the researcher had seen v1's results, so those dates are also seen. Only the forward period, from 2026-12-01, is confirmatory.

Source: src/trend/v3/labels.py, v3 pre-registration

Uncertainty

Sharpe intervals come from a stationary bootstrap of daily returns.

Sharpe is annualised from daily net returns. The 95% interval is a stationary bootstrap (mean block 20 days, 500 draws, seed 0); the paper tables use 2000 draws, so the lab's interval can differ slightly. v1's headline tests are monthly.

Source: docs/trend_lite.py, data/meta.json

Data

Free public futures and FX/rates series, frozen on 2026-11-21.

Continuous futures and FX/rates series from free public sources, frozen on 2026-11-21 (last market date 2026-11-20). Holidays are zero-filled after each market's first observation.

Source: results/v3/DATA_VINTAGE.md, scripts/v3/export_site_data.py
